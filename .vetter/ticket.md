# Add a "Docs" link to the main navigation

Add a "Docs" link to the top navigation bar of the signed-in Dify
UI that opens https://docs.dify.ai in a new tab.

## How to reach the app

Dify runs on http://localhost. First-time use requires completing the
/install wizard to create the admin account, then signing in.

## Acceptance

- A "Docs" link is visible in the top navigation on any signed-in page.
- Clicking it opens https://docs.dify.ai in a new tab
  (target=_blank, rel=noopener).
- No existing nav items are moved or removed.
